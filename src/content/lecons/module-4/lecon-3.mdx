Une commande rassemble tout ce qu'il faut pour transmettre le cours.

```bash
npm run bundle
```

## Ce que vous obtenez

```
dist/
  index.html, lecons/…        le site
  _astro/, fonts/             ses assets
  slides/
    index.html                sommaire des présentations
    module-1-lecon-1.html     deck projetable
    module-1-lecon-1.pdf      même deck, imprimable
    assets/                   images des decks
  LISEZ-MOI.txt               mode d'emploi pour le destinataire
```

L'ordre des opérations compte : `npm run build` **vide** `dist/` à chaque passage, donc les présentations y sont ajoutées après. C'est tout ce que fait la commande de bundle.

## La limite à connaître avant d'envoyer le dossier

C'est le point qui surprend, et il vaut mieux le savoir avant que le destinataire ne s'en plaigne.

| | Ouverture par double-clic | Servi en HTTP |
| --- | --- | --- |
| Le site | ✗ | ✓ |
| Les decks HTML | ✓ | ✓ |
| Les PDF | ✓ | ✓ |

**Le site a besoin d'un serveur.** Il charge ses scripts sous forme de modules, que les navigateurs refusent de charger depuis un simple fichier local. Ouvrir `dist/index.html` par double-clic donnerait une page bien mise en forme mais **sans progression, sans quiz et sans glisser-déposer** — le pire des cas, puisque ça a l'air de marcher.

Deux façons de le servir :

- **en ligne** : déposez le dossier chez n'importe quel hébergeur de site statique ;
- **en local**, sans rien installer :

```bash
cd dist
python3 -m http.server 8000
```

Puis `http://localhost:8000`.

**Les présentations, elles, s'ouvrent hors ligne.** Les polices sont embarquées dans chaque fichier HTML. Seules les images vivent dans `slides/assets/` — gardez donc le dossier `slides` entier si vous le déplacez. Un PDF, lui, se transmet tout seul.

## Le mode d'emploi voyage avec le paquet

Le fichier `LISEZ-MOI.txt` répète tout cela **dans** `dist/`, avec la ligne de commande à copier. C'est délibéré : le destinataire n'aura pas ce cours sous les yeux au moment d'ouvrir le dossier.

## Où publier

N'importe quel hébergeur de fichiers statiques convient : Netlify, Vercel, GitHub Pages, ou un simple dossier servi par Apache ou nginx. Il n'y a ni serveur applicatif à installer, ni base de données à configurer, ni variable d'environnement à renseigner — c'est le bénéfice du choix statique expliqué au module 1.

Pensez simplement à `npm run build` avant de publier : c'est aussi lui qui valide les en-têtes de vos leçons.
